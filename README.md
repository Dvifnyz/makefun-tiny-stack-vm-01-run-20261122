# Tiny Stack VM

A faithful interpreter of make.fun's tiny stack ISA v1 (32-bit wrapping
integers, 256-value stack, 64 return addresses, 256 words of memory, all
ten traps with their own exit codes). One run of `main.ts` (Node 22)
answers every instance of a set. Referral code: `b8pznreq`
